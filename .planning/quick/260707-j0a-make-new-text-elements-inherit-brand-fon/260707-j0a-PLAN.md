# Quick Task 260707-j0a: New text elements inherit DDROIDD brand font

## Problem

Dragging a generic plugin block (Text / Button / Social — kept via `resetBlocks: false`)
drops an `mj-text` / `mj-button` / `mj-social-element` with **no font attributes**. On the
canvas these render in the grapesjs-mjml default font, not the DDROIDD brand font, so a
newly-added text element looks inconsistent next to branded blocks (which inline
`BLOCK_DEFAULTS`).

**Exported HTML is already correct** — the server-injected canonical `mj-head`
(`app/server/src/services/compile.ts`) sets `font-family` (mj-all) + `line-height`/`font-size`
(mj-text) via `mj-attributes`. The canvas has no injected head, so the gap is **canvas-visual
only**.

## Approach

Add a fill-missing listener in `editorConfig.ts` `onEditor`:

- Event: **`block:drag:stop`** (fires only on a real block drop). Deliberately NOT
  `component:create` / `component:add` — those fire during `loadProjectData`, which would
  mutate loaded generic text and break the Phase-1 round-trip gate (`assertRoundTrip`,
  `actions.ts:151`). `block:drag:stop` keeps save→load byte-identical.
- Recurse the dropped component tree; for every component whose type is font-bearing
  (`mj-text` / `mj-button` / `mj-social-element`, derived from `STYLABLE_BY_TYPE` entries that
  include `font-family` — one source of truth), fill any **missing** `font-family` /
  `font-size` / `line-height` from `BLOCK_DEFAULTS` via `addAttributes`.
- **Fill-missing only** (never overwrite): branded blocks already carry these attrs, so they
  are untouched; idempotent.
- **`color` is deliberately NOT set.** `BLOCK_DEFAULTS.textColor` is `#ffffff`; a generic block
  can land in a light section → white-on-white (the documented white-default-text trap,
  `mjml-email-safety.md`). Text color is owned by the server head at export.

## Tasks

1. Wire the `block:drag:stop` fill-missing font listener into `editorConfig.ts` `onEditor`,
   deriving font-bearing types from `STYLABLE_BY_TYPE` and pulling values from `BLOCK_DEFAULTS`.

## Done when

- Dragging the generic Text block onto the canvas shows brand font (Calibri stack), 16px,
  24px line-height — matching branded blocks — with text color left to the section/head.
- Branded blocks and loaded project data are unchanged (round-trip still byte-identical).
- `tsc` / build clean.

## Verify

  the brand font-family/size/line-height on the new element.
- Regression: `window.__ddroiddAssertRoundTrip()` still logs `Round-trip identical: true`.
