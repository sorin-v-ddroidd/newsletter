<objective>
The Alignment control writes the CSS `text-align` property. On mj-text/mj-button/mj-image/mj-divider/mj-social-element this serializes to an ILLEGAL MJML attribute (`text-align="…"`) that the MJML compiler ignores — so alignment does nothing on the canvas (the plugin's `align="left"` style-default wins) and nothing in the exported email. The MJML attribute for horizontal alignment on those components is `align`. `text-align` is legal ONLY on mj-section.

Fix: expose an `align` style property, scope it to the components whose MJML uses `align`, and keep `text-align` scoped to mj-section alone.

Purpose: Alignment control actually aligns content on canvas and in exported HTML — closes a real user-facing bug (verified live 2026-07-10 on localhost:5174).
Output: 3 edited editor files; no schema/API changes.
</objective>
