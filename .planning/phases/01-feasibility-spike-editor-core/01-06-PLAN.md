<objective>
Close the two diagnosed blockers from 01-UAT.md that prevent the Phase 1 feasibility
spike from being verifiable by a human:

1. **No blocks panel** — `<Canvas />` as a child of `<Editor>` puts @grapesjs/react into
   custom-UI mode (`customUI: true`, `panels: { defaults: [] }`), which suppresses the
   default Block Manager UI. Registered blocks exist in `editor.Blocks` but have no surface
   to drag from. Fix: remove the `<Canvas />` child so `<Editor>` runs default-UI mode and
   the stock GrapesJS chrome (blocks panel, style manager, layers, device bar) renders.

2. **/api/compile 502** — `app/package.json`'s dev script uses `&` to chain the two dev
   servers, which is SEQUENTIAL under cmd.exe on Windows; Vite never exits, so `dev:server`
   never starts and nothing listens on :3000 → the Vite proxy returns 502. Fix: add
   `concurrently` and run both in parallel.

Purpose: unblock UAT tests 3-6, 8-10 (currently blocked/failed) so the human can complete
the Phase 1 runtime verification and prove the grapesjs@0.22.16 + grapesjs-mjml@1.0.8 triple.
Output: an editor that shows a blocks panel, and a `npm run dev` that boots both servers.
</objective>
