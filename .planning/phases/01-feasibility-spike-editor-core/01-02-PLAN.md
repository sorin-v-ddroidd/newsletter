<objective>
Scaffold the `app/server` Express + TypeScript backend and implement `POST /api/compile`, which compiles editor MJML to client-safe HTML using `mjml@4.18.0` and writes the result to repo-root `dist/spike-output.html`. This is the server half of the Walking Skeleton, independently verifiable via curl with a hardcoded sample fragment.

Purpose: Provide the authoritative server compile that matches the bundled `mjml-browser@4.18.0` for preview/export parity, with the conditional-wrap logic that makes it robust to the LOW-confidence `editor.getHtml()` return shape. The server (not the browser) owns the filesystem write of `dist/spike-output.html` — the file the Plan 05 client-render gate consumes. Foundation code per D-01.
Output: A running Express server on :3000 where `POST /api/compile` returns compiled HTML AND persists it to `dist/spike-output.html`, with the T-01-01 (body limit) and T-01-02 (CORS) mitigations in place.
</objective>
