<interfaces>
Apply the SAME uniform rule proven on hero.ts in Plan 01:
  every top-level `<mj-section>` opening tag → add `data-gjs-draggable="false" data-gjs-removable="false"`
  every `<mj-column>` opening tag           → add `data-gjs-droppable='["mj-text","mj-image"]'`
  `<mj-text>` / `<mj-image>` tags            → add NOTHING (defaults keep them editable/movable/removable)
Single-quote the droppable attribute so its JSON array double-quotes survive.
Never self-close mj-* tags (grapesjs.md) — only ADD attributes to existing open tags.

Consistency payoff (already in the codebase, verify only — no code change):
- LeftSidebar.tsx gates its delete icon on `component.get('removable') !== false`.
- actions.ts `canDuplicate` excludes `removable === false`.
Once `data-gjs-removable="false"` lands on a branded section, both the Layers delete icon and the
duplicate action respect it automatically.

If Plan 01 had to teach verify-blocks.ts to strip data-gjs-* (its SUMMARY says so), the gate already
handles these 6 blocks the same way — no further gate change needed.
</interfaces>
